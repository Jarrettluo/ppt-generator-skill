# Ppt Generator

> 将用户讲稿一键生成乔布斯风极简科技感竖屏HTML演示稿。当用户需要生成PPT、演示文稿、Slides、幻灯片，或要求科技风/极简风/乔布斯风格的演示时触发此技能。输出为单个可直接运行的HTML文件。

## 安装

将本仓库放到 OpenClaw 技能目录即可使用：

```bash
git clone <本仓库地址> ~/.openclaw/workspace/skills/ppt-generator-skill
# 或放入 ~/.openclaw/skills/
```

## 配置

如需 API Key、邮箱授权码等配置，请参考 `SKILL.md` 中的说明，通过环境变量或本地 `.env` 文件设置（**不要提交到仓库**）。
